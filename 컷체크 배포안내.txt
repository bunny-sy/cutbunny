   ✂ 컷 체 크   —  설치 & 사용 안내
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

캡컷으로 편집할 때, 컷마다 몇 초인지 옆에서 실시간으로 보여주는 도구예요.
"3초 컷" 목표에 맞는지 색으로 바로 알 수 있어요. (초록=좋음 / 노랑·빨강=길다)


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  1. 설치하기                        ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

① 아래 링크에서 「CutCheck_x.x.x_x64-setup.exe」를 받아요
   → https://github.com/bunny-sy/cutbunny/releases/latest

② 받은 파일을 두 번 눌러 설치해요


   ⚠ "Windows의 PC 보호" 파란 창이 뜨면? (정상이에요!)
   ─────────────────────────────────────
   유명 프로그램이 아니라서 뜨는 안내창일 뿐, 안전해요.
   → "추가 정보" 클릭  →  "실행" 버튼 클릭
   그러면 설치가 진행돼요.
   (백신이 막으면 "허용" 눌러주세요)


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  2. 처음 켰을 때                     ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

디하클 닉네임을 입력하는 창이 떠요.
→ 단톡방에서 쓰는 닉네임 그대로 입력하고 "시작하기"

  · 한 번만 입력하면 다음부턴 안 물어봐요.
  · "등록되지 않은 닉네임"이라고 나오면 관리자(버니)에게 알려주세요.


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  3. 사용법                          ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

① 캡컷을 켜고 편집할 프로젝트를 열어요
② 컷체크를 켜요 (항상 위에 떠 있어요)
③ 캡컷에서 컷을 자를 때마다 → 컷체크에 길이가 실시간 표시!

  · 맨 위 = 방금 자른 최신 컷
  · 초록(~3초 좋음) / 노랑(3~4초) / 빨강(4초 넘음, 더 자르기)
  · 맨 아래 "아직 안 자른 부분" = 편집 안 한 뒷부분 분량
  · 캡컷을 안 켜도 되지만, 같이 켜두고 쓰면 편해요


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  3-1. 내 목표에 맞게 색 바꾸기        ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

컷 목표가 3초가 아니라면? 오른쪽 위 톱니 버튼(⚙)을 눌러보세요.

  · [간단] 슬라이더로 목표 길이만 정하면 나머지 색은 자동으로 맞춰져요
  · [직접] 색마다 기준 숫자를 직접 넣을 수도 있어요
  · 한 번 정하면 계속 저장돼요

  색 의미:
   초록 = 목표 안쪽 (좋아요!)
   노랑 = 살짝 길어요
   빨강 = 너무 길어요 (더 자르기)
   회색 = 너무 짧은 잔컷


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  4. 업데이트                        ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

따로 다시 받을 필요 없어요!
새 버전이 나오면 앱을 켤 때 "업데이트할까요?" 창이 떠요.
→ "업데이트" 한 번만 누르면 알아서 최신으로 바뀌어요.


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  5. 삭제할 때 (참고)                 ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

지울 일이 있으면 그냥 "Uninstall" 누르면 돼요.
