아래 순서대로 따라 하면 설치 끝 — 3분이면 돼요

1

파일 받기

아래 파란 버튼을 누르면 설치파일이 바로 받아져요. (한 번만!)

⬇ 컷체크 설치파일 받기
2

파란 경고창 넘기기

받은 파일을 두 번 누르면 "Windows의 PC 보호" 창이 떠요.
정상이에요! 안전합니다.

Windows의 PC 보호
인식할 수 없는 앱의 시작을 차단했습니다.

추가 정보 ① 먼저 클릭
앱: CutCheck_0.2.1_x64-setup.exe
실행 ② 그다음 클릭 실행 안 함
!유명 프로그램이 아니라 뜨는 안내일 뿐이에요.
"추가 정보" → "실행" 순서로 누르면 설치돼요.
(백신이 막으면 "허용")
3

닉네임 입력 (처음 한 번)

설치 후 처음 켜면 이 창이 떠요.
디하클 단톡방 닉네임을 그대로 입력!

✓한 번만 입력하면 다음부턴 안 물어봐요.
"등록되지 않은 닉네임"이 뜨면 버니에게 알려주세요.
4

이렇게 써요

캡컷 옆에 띄워두면,
컷을 자를 때마다 길이가 색으로 바로 보여요. (맨 위 = 최신 컷)

초록 = 목표 안쪽 (좋아요!) 노랑 = 살짝 길어요 빨강 = 너무 길어요 (더 자르기) 회색 = 너무 짧은 잔컷
5

내 목표에 맞게 색 바꾸기

컷 목표가 3초가 아니라면?
오른쪽 위 톱니 버튼을 눌러 목표 길이를 바꿔보세요.
